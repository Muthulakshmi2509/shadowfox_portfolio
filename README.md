## 📌 Overview

This portfolio serves as an honest representation of my academic background as a B.Tech student at **Manakula Vinayagar Institute of Technology (MVIT)** and my ongoing software development training through **NxtWave CCBP 4.0**.
<img width="1870" height="903" alt="image" src="https://github.com/user-attachments/assets/b8c9eb40-8db1-4b53-ab40-a27e4ff1dd42" />


### Key Features
- **Interactive UI**: Dynamic typing animation, filterable skill cards, and expandable timeline details.
- **Theme Switcher**: Smooth Dark/Light mode toggle with session memory.
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop screens.
- **Zero Framework Dependency**: Built purely with semantic HTML5, modern CSS3, and vanilla JavaScript.
